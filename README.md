# 音乐推荐 · Music Recommender

音乐推荐为 AstrBot 提供搜歌工具，让 AI 在聊天中查找并推荐网易云音乐或QQ音乐的歌曲，返回歌名、歌手与播放页面链接，或发送QQ音乐卡片。

本版本：**1.0.1**。音乐搜索可由模型调用；QQ卡片需要相应消息适配器与可用的卡片发送条件。

## 主要功能

- 使用歌名、歌手或主题关键词搜索网易云音乐、QQ音乐。
- 由模型结合对话调用 `search_music` 工具并说明推荐理由。
- 提供歌名与链接、机器人签名卡片、独立签名卡片、本地实验卡片四种发送方式。
- 调整结果数量、卡片数量、专辑、时长、链接和搜索等待时间。
- 卡片发送全部失败时，将歌曲信息交给模型以文字继续说明。

## 安装与开始使用

1. 在 AstrBot 中配置支持工具调用的模型，并确认普通聊天可用。
2. 将 `astrbot_plugin_music_recommender` 放入 `data/plugins` 并加载。
3. 插件配置 → 开始使用，启用音乐搜索，选择音乐平台。
4. **没有签名服务时，将发送方式改为“歌名与播放链接”。** 旧设置的默认发送方式仍为机器人签名卡片，升级不会擅自切换。
5. 保存并重载插件，在聊天中说“帮我找一首周杰伦的歌”或“推荐几首适合散步的歌”。模型按需要调用工具。

插件没有独立的 `/音乐` 搜索指令。是否调用工具、怎样介绍结果，由当前模型和 AstrBot 的工具调用配置决定。搜索得到播放页面，不表示提供会员音源下载或保证直接播放。

## 升级

旧设置会迁移到分组并保留原值。修改后保存并重载，重新读取搜索与卡片设置。本插件不建立聊天或长期记忆数据库；它不会替代光谱与棱镜的状态系统。
